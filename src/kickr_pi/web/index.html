Training plan

Generate bike + run weeks here. Playable bike sessions appear in Home Library (Source: Plan). With an Anthropic API key, Claude sketches the week; ERG stages are built on-host. Without a key (or on API failure), the built-in rules planner is used. After any ride ≥30 min the next week is regenerated automatically.

Claude (optional)

Paste an Anthropic API key to use Claude for plan sketches. Training load and goals are sent to Anthropic only when you Generate (or after a long ride). ERG stages stay on-host. Leave the key empty to use the rules planner only.

  1. Create a key at console.anthropic.com.
  2. Paste it below, choose a model (default works for most riders), then tap Test connection.
  3. When the test succeeds, tap Save. Generate will prefer Claude.

Trainer

Real KICKR uses Wahoo Direct Connect (mDNS _wahoo-fitness-tnp._tcp). Emulator is for desk development — you can switch it on or off even when the bike is offline. Controls appear on the ride screen.

Seeing lower watts on Strava?

        

          Short 0 W gaps while you're pedalling mean the watch is losing the signal.
          Remove duplicate KICKR pairings, keep only ANT+, and keep the watch close to the
          trainer (on the handlebars works best).
